# SKYLENS 

Satellite tracker application for iOS environment
Full-Stack application using C++ and Swift for the backend and mainly SwiftUI for the frontend

--- 

### Features
- Search by name, NORAD or TLE
- Access to default favorites and able to create your own for quick access
- Toggle between single-point-in-time and groundtrack mode
- Ability to select different time frames in the input section
- Fetches TLE from Celestrak and computes the coordinates using SGP4 orbit propagator modelled in the C++ backend
- Both 2D map and 3D map available
- Computes AOS and LOS given coordinates of a point of interest (i.e. ground station)
- Evaluate strength of signal prediction for specific passes
- Setup alerts for upcoming passes or visibility windows
